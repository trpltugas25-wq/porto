What is Our Project

What is our project ?, We're literally making an Ai Chatbot using the thing called STB and something called N8N. Through an platform called Telegram. But how does it work, so the bot uses N8N as it's operator then connected to a device called STB as an server, where users can interact with the bot using that previous app we talked about. And thats what our project does.

How we Made it

We made this project by using an unused STB device as it's server. But here comes the question that you've all might ask about our project "Why you're using that thing?". So the answer to it's we know that buying a new and fully functionalized server would cost much more, So to solve it we search some solutions on the internet then we've found a simple tutorial how to make a low cost server by reusing and repurposing an old STB device, so by that we can save more and use it for other, and also by doing this we can help saving the enviroment too by reusing the unused device.
